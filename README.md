Repositório dedicado aos meus estudos e experimentações com a biblioteca **Pandas** em Python. O objetivo aqui é documentar minha evolução na manipulação, tratamento e análise de dados durante minha jornada na Engenharia de Software.

## 📚 O que você vai encontrar aqui (Conteúdo em expansão)

- **Leitura e Escrita de Dados:** Como importar e exportar arquivos `.csv`, `.xlsx`, entre outros.
- **Manipulação de DataFrames e Series:** Seleção, filtros e ordenação de dados.
- **Agrupamentos e Operações:** Uso de `groupby`, agregações e estatísticas descritivas básicas.

## 🛠️ Tecnologias e Ferramentas

- **Python 3.x**
- **Pandas**
- **Jupyter Notebook / VS Code** (Recomendado para visualização interativa dos dados)

## 🚀 Como executar os scripts

1. Clone este repositório:
   ```bash
   git clone https://github.com/Magno-cyber/Pandas.git
   ```
2. Acesse a pasta:
   ```bash
   cd Pandas
   ```
3. Instale o Pandas (caso não tenha):
   ```bash
   pip install pandas
   ```
4. Rode os arquivos `.py` no seu terminal ou abra os arquivos `.ipynb` na sua IDE de preferência.
